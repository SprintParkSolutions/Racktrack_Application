# rsync excludes for pushing this checkout to the demo VPS.
#
#   rsync -avz --progress --exclude-from=deploy/demo-rsync-excludes.txt \
#     ./ root@82.29.164.213:/opt/racktrack-demo/
#
# Why this exists rather than `git clone` on the box: the repo is private and
# the VPS has no GitHub credentials. Why it exists rather than reusing
# .dockerignore: rsync cannot read that file, and its `!negation` syntax means
# the two are not interchangeable anyway.
#
# Takes the checkout from ~2 GB to ~16 MB. The big offenders are not obvious:
# .venv alone is ~900 MB (a Windows virtualenv carrying torch's DLLs, which are
# useless on Linux and get reinstalled from the CPU wheel index in the image
# anyway), and server.zip is another 106 MB.
#
# Models/ is excluded here and sent separately — see docs/setup/DEMO-VPS-SETUP.md.
# Keep this list in step with .dockerignore when that changes.
