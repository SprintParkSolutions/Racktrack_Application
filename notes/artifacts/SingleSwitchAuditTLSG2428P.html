8Hosts & cable trace

With a single switch, a “trace” is short: switch port → (patch panel, if any) → wall outlet → device. Fill one row per live port. The switch tells you the two logical ends (MAC table + LLDP); you add the passive middle from the port label / patch record.

Label scheme to adoptWrite each port/label as SG2428P:Gi1/0/7 and each patch-panel port as PP:07. Put the same ID at both cable ends and in this table — that is what makes the next trace instant.
