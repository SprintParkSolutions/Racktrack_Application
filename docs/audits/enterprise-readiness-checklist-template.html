Live run log — what we executed against this template today august 19, 2026 · branch publish/main

npm audit (client + server): every advisory with an available patch is fixed and verified by re-running all 240 tests. Two exceptions stand documented: one advisory with no patched release anywhere (an install-time-only code path), and one requiring a framework major migration — both triaged, neither reachable by an attacker in production.

pip-audit (AI pipeline): no known vulnerabilities across the full Python requirements. Clean on first run.

Semgrep SAST (first-ever run): 33 findings — 9 critical-severity, 24 warnings. All 9 criticals were manually verified and are false alarms: four are log messages the scanner mistook for SQL; two are integer-only ID lists (safe by construction, and commented as such in the code); two build SQL column names from a code-side whitelist with parameterized values; one flags a process launch whose command comes from server config, not users. The 24 warnings are logged for review — the sampled ones are already mitigated upstream by shape-validation and ownership checks on rackId. Net result: zero real vulnerabilities found in our own code.
