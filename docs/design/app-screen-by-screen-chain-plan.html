A rack is now a chain

Today a rack is a row of tabs — go anywhere, any order. That stops working once the job has an order: you can't review disagreements before reading the switches, and you can't export before someone has settled them.

So the rack shows six steps instead. A finished step has a tick. The one you're on is highlighted. A step that can't work yet is locked and says why.

The five changes, in full

New

Compare

You're filling rack data into NetBox by hand anyway. This puts the two side by side and names every difference: in the rack but not the record, in the record but not the rack, or there in both and different.

New

Review

Nothing is written until a person has looked at each disagreement and chosen. No value goes in without a source behind it.

New

Export

Today a scan quietly opens a ServiceNow ticket in the background. This makes it a thing you do and can see — preview what will change first, then send it, to either system or both.

Changes

Ports

Same screen, same place. Instead of logging into switches over SSH from the server, the phone asks them over SNMP — which is what finally lets it work from inside your customer's network.

Changes

Data Sources

It already lists NetBox with nothing behind it. Now it works, and it's where a NetBox login is entered once for the whole organisation — so nobody is asked for a password while standing at a rack.

Goes

The Network tab

The old Netdisco view, hidden behind More on a phone. Its name now clashes with step 3, and step 3 does the job better.

On a phone

The bar holds four things. Today they're four equal tabs, and whatever doesn't fit hides behind More — which is where Network and Drift live, and testers reported not knowing they existed.

A chain fixes that, because it knows which step you're on. The bar follows the work: finished steps stay visible as ticks, the next one is always one tap away.

Where to start

Turn the rack tabs into the chain first, using only the three screens you already have — Scan, Physical, Ports. No new code, nothing new to learn, and an afternoon to undo if it doesn't feel right. It puts the pattern in front of real testers before a single new screen is built.

Then, in order: Ports moves to SNMP, Data Sources gets NetBox, and Compare, Review and Export arrive one at a time.
