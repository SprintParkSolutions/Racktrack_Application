Why the connection is only temporary

The catch with today's tunnel

The tunnel's web address is random, and it changes whenever the Mac restarts (a reboot, sleep, or closing the window). That address is locked inside the installed app and can't be changed after install.

So if it changes, every tester's app stops working until we rebuild the app with the new address and upload it again. Fine for a quick demo — not fine for ongoing testing. That's what the plan below fixes.

★

The plan: a permanent address on a fresh domain

Nothing to break

With a brand-new domain there's no live website sharing it, so you skip the careful "copy the old records first" step entirely. The cleanest option is to register the domain directly with Cloudflare — then its address system is on Cloudflare from minute one, with no nameservers to move.

  1. Register a domain with Cloudflare

    Pick any name (e.g. racktrack-app.com) and buy it through Cloudflare Registrar. Its address system is on Cloudflare instantly — no nameserver change, no waiting.

  2. Create the tunnel and claim the address

    One-time setup that links the Mac and gives the app its fixed address (here, api.racktrack-app.com).

    cloudflared tunnel login
cloudflared tunnel create racktrack
cloudflared tunnel route dns racktrack api.racktrack-app.com

  3. Forward it to the app's backend and keep it running

    Send the address to the Mac's server (port 3001) and install it as a service so it restarts by itself after a reboot.

    # ~/.cloudflared/config.yml points the hostname to localhost:3001
sudo cloudflared service install

  4. Rebuild the app once with the new address

    The last rebuild just for the address. Upload it and point testers at the new build.

    ./make-ipa.sh 6GS882NNAX https://api.racktrack-app.com
Bought the domain at GoDaddy / Namecheap instead?

Still fine — add one extra step: put the new domain on a free Cloudflare account and point its nameservers to Cloudflare (no website on it, so nothing to lose). Once it shows Active, continue from step 2. Registering directly with Cloudflare just skips this.
