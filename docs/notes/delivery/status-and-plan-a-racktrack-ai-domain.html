Why the connection is only temporary

The catch with today's tunnel

The tunnel's web address is random, and it changes whenever the Mac restarts (a reboot, sleep, or closing the window). That address is locked inside the installed app and can't be changed after install.

So if it changes, every tester's app stops working until we rebuild the app with the new address and upload it again. Fine for a quick demo — not fine for ongoing testing. That's what the plan below fixes.

★

The plan: a permanent address on racktrack.ai

Website and app live side by side

Your website already lives at racktrack.ai. The app just needs its own address on a subdomain — adding one never affects the main website.

racktrack.ai→ your website — untouched, stays where it is
www.racktrack.ai→ your website — untouched
api.racktrack.ai→ the app — new subdomain pointing to your Mac
The one thing to be careful about

The tunnel needs Cloudflare to manage racktrack.ai's addresses, which means pointing the domain's nameservers at Cloudflare — that moves DNS for the whole domain, website included. It's safe in the right order: Cloudflare copies your existing website records first, you confirm they all came across, and only then switch the nameservers. The website's content and hosting don't change.

  1. Add racktrack.ai to a free Cloudflare account

    Sign up, click Add a site, enter racktrack.ai. Cloudflare imports your current website records automatically.

  2. Check the website records carried over

    Compare the imported list with GoDaddy — the records pointing racktrack.ai and www at your site must all be present. This keeps the site up.

  3. Point the nameservers to Cloudflare

    In GoDaddy, set the domain's nameservers to Cloudflare's two. Wait until it shows Active. The website keeps serving throughout.

  4. Create the tunnel and claim api.racktrack.ai

    cloudflared tunnel login
cloudflared tunnel create racktrack
cloudflared tunnel route dns racktrack api.racktrack.ai

  5. Forward it to the app's backend and keep it running

    Send api.racktrack.ai to the Mac's server (port 3001) and install it as a service so it restarts by itself after a reboot.

    # ~/.cloudflared/config.yml points the hostname to localhost:3001
sudo cloudflared service install

  6. Rebuild the app once with the new address

    The last rebuild just for the address. Upload it and point testers at the new build.

    ./make-ipa.sh 6GS882NNAX https://api.racktrack.ai
