Why it's only temporary

The catch with today's tunnel

The tunnel's web address is random, and it changes whenever the Mac restarts (a reboot, sleep, or closing the window). That address is locked inside the installed app and can't be changed after install.

So if the address changes, every tester's app stops working until we rebuild the app with the new address and upload it again. Fine for a quick demo — not fine for ongoing testing.

★

The plan: make it permanent with racktrack.ai

The goal

Use your GoDaddy domain racktrack.ai to give the tunnel a fixed address — api.racktrack.ai — that never changes. We bake that into the app one time, and after that a Mac restart no longer breaks anything. Yes, the GoDaddy domain works for this.

  1. Connect racktrack.ai to Cloudflare

    Keep the domain at GoDaddy, but change its nameservers to the two Cloudflare gives you (free account). This lets Cloudflare manage the address. Wait until it shows Active.

  2. Create a permanent tunnel on the Mac

    One-time setup that links this Mac and creates a named tunnel.

    cloudflared tunnel login
cloudflared tunnel create racktrack

  3. Give it the fixed address

    This is the address that never changes.

    cloudflared tunnel route dns racktrack api.racktrack.ai

  4. Point it at the app's backend and keep it running

    Forward api.racktrack.ai to the Mac's server, and install it as a background service so it comes back on its own after a reboot.

    # in ~/.cloudflared/config.yml: forward to localhost:3001
sudo cloudflared service install

  5. Rebuild the app once with the new address

    The last time we rebuild just for the address. Then upload the new build and point testers at it.

    ./make-ipa.sh 6GS882NNAX https://api.racktrack.ai

One day, beyond this

The permanent tunnel still keeps the backend on your Mac, which is perfect for testing. Later, if you want, the whole backend can move to an always-on server so the Mac isn't needed at all. That's a separate step — the domain plan above is the right next move and unblocks stable testing now.
