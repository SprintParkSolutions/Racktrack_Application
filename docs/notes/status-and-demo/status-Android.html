Android app — detailed status

For each thing we did: what it is, how it works, what we’re using, the effect it has, and what’s needed to make it permanent & stable.

1

App branding & icon

What we did
Set the RackTrack logo as the Android launcher icon at every size (including the modern “adaptive” icon shape).
How it works
The logo is generated into each Android icon size and compiled into the APK.
What we’re using
The app’s Android icon folders + macOS image tools.
Effect
Real RackTrack brand on the Android home screen — consistent with the iPhone app.
To keep stable
Nothing further — baked into every APK.
2

Built the installable APK

What we did
Installed Android Studio and produced a working APK file (~11 MB) with the tunnel address baked in.
How it works
The same shared web app is wrapped into a native Android app and compiled into a single APK file that installs directly on a phone.
What we’re using
Android Studio (build tool) · Capacitor Android · a debug build (fine for testing).
Effect
We can hand testers one file to install — no app store, no account, no review, no fee.
To make stable
For the Play Store later, we’d make a signed release build (see plan below). Not needed for current testing.
3

Android scrolling — fixed

What we did
On some Android phones the pages wouldn’t scroll at all. Fixed across the whole app.
How it works
The app sized its scroll areas with a newer screen-measurement unit that older Android app-browsers don’t understand, which collapsed the scroll areas. We switched to the standard unit that every Android supports — it looks identical in a full-screen app.
What we’re using
The app’s styling (a one-line-per-place unit change).
Effect
Pages scroll properly on Android now — content below the fold is reachable.
To confirm stable
Install this new APK on the phone that had the problem and confirm scrolling works.
4

Same app improvements as iPhone

What we did
Android gets all the shared fixes: scan not lost when switching apps, back buttons never stick, first-time walkthrough, compact Ports screen, and the “No switches detected” message on the Network screen.
How it works
iPhone and Android run the same app code, so one fix applies to both. Android also has proper hardware Back button support.
What we’re using
The shared app + Android’s native back handling.
Effect
Feature-for-feature parity with the iPhone app.
To keep stable
Stable — same as iOS.
5

Camera & AR

What we did
Camera scanning and the AR overlay are both built for Android natively.
How it works
Normal photo/camera scanning works on any Android phone. The AR overlay uses Google’s ARCore.
What we’re using
Android camera permission (already set) + Google ARCore for AR.
Effect
Everyday scanning works everywhere; the AR overlay works on ARCore-supported phones.
To keep stable
Note in tester instructions: AR needs an ARCore-supported phone with “Google Play Services for AR” installed. Regular scanning is unaffected.
6

The backend & the temporary tunnel ← the important one

What it is
Exactly like the iPhone app, Android talks to our Mac for the AI and the live switch read — the phone itself doesn’t do the heavy work.
How it works
The APK has a web address baked in that points, through a Cloudflare tunnel, to the Mac’s server.
What we’re using
The same Mac server + temporary Cloudflare tunnel as the iPhone app.
Effect
Works while the Mac + server + tunnel are up. The address is random and changes if the Mac restarts — then the APK can’t reach the server and we’d have to rebuild.
To make permanent & stable
Same plan as iPhone — a fixed address + an always-on server (below).

⚠ To make it permanent & stable

  1. Fixed web address. Point api.racktrack.ai to a permanent Cloudflare tunnel so the address never changes — a Mac restart no longer breaks the app and we stop rebuilding for the address.
  2. Always-on backend. Run the server as a proper service so it’s always up — this is essential because the Mac can’t stay on all the time.
  3. Move off the Mac (key). Put the backend + AI on a dedicated always-on machine so the app works even when the Mac is off.
  4. Real-device test. Install this APK on real Android phones and confirm scrolling + scanning.
  5. Optional — Play Store. A signed release build + Google Play Console (one-time $25) if we want store distribution instead of sharing the file.
