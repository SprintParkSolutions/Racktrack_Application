RackTrack · Overview

Today’s progress & what’s left

RackTrack scans a server rack from a photo and shows every device, its position, and live switch-port info. Today we got it running on both iPhone and Android for testers, and fixed the issues testers hit.

💬 Summary to read out

“RackTrack now runs on both iPhone and Android. On iPhone it’s on Apple TestFlight; on Android we have an installable app file. Today I put our real logo on both apps and fixed the main issues testers were hitting — scans no longer get lost when you switch apps, the ‘load failed’ error is gone, and back buttons, scrolling, and a first-time walkthrough all work now.

The one thing left before we open it to testers: right now the app depends on my Mac being switched on, because the AI and the live switch-reading run there. I can’t keep my Mac on all the time, so the key next step is moving that part to an always-on server with a permanent web address. Once that’s done, testers can use the app anytime, on their own — without needing my machine running.”
