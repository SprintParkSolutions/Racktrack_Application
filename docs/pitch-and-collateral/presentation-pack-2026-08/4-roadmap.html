Next · what's left to build

What still needs building

With the quick fixes done, three real things stand between RackTrack and enterprise-ready — and most of them arrive together as part of the cloud move.

the operational backbone
○ BIGGEST

A real database, with backups

Today Data lives in one file + folders on one disk, with no backups. A crash mid-save can orphan a scan; a dead disk loses everything.
Why it's #1 It's the scariest risk we have, and it's the thing certificates specifically check for.
Fix A managed PostgreSQL database (atomic saves) + automatic nightly backups + one tested restore. Comes with the cloud move.
○ SALES BLOCKER

Company sign-in (SSO)

What it is Letting staff sign in through their organisation's own login system.
Why it matters Many companies can't buy software without it. Note: since our users are datacenter technicians on company accounts (not Microsoft/Google), this is standard SSO to whatever system the customer uses — not tied to one provider.
Fix Add standard SSO + move the login token into a safer cookie.
○○

Alerts + a test server

Today If it breaks at 2am, a tester tells us hours later. Updates are copied by hand with no undo.
Fix An uptime monitor + crash reports (alerts to a phone), plus a staging server and one-button deploys with rollback. Both come with the cloud move.
◐ IMPROVING

Test coverage & capacity

Now Coverage is measured (server ~48%, pipeline ~12%, screens ~2% — the screens are covered by the browser sweep instead). Still unknown: how many users the AI scan handles at once.
Fix Set a coverage floor so it only rises, and run a load test against the new test server.
○ OPTIONAL

A quality dashboard (SonarQube)

What it is Not a new check — a dashboard that tracks quality over time (bugs, duplication, coverage trends) in one visual place.
Needs a decision It requires either a hosted account or a server of our own. Worth adding for visibility once we choose.
The efficient part: the database, backups, monitoring and staging aren't four separate projects — they're delivered together by moving to the cloud. That's the next tab.

Next · the cloud move

Moving to the cloud — AWS or Azure

Moving off our single server onto a proper cloud is how we deliver the database, backups, monitoring, scaling and safe deploys. Both AWS and Azure do the job well; the choice comes down to one factor.

decision needed leaning AWS

What each part becomes

TodayAWSAzure
The API serverECS FargateContainer Apps
Account databaseRDS PostgreSQLAzure DB for PostgreSQL
Scan photosAmazon S3Blob Storage
The AI pipeline (GPU)SageMaker / GPU ECSAzure ML
Monitoring & alertsCloudWatchAzure Monitor
Company sign-inCognitoMicrosoft Entra ID
The one real difference: almost everything is equivalent. The exception is heavy AI (GPU) work, where AWS leads on choice and cost — and that's our biggest, most expensive workload.

The recommendation

Lean AWS. RackTrack is an AI-first product, and AWS is strongest for the GPU/AI work. The usual reason to pick Azure — native "Sign in with Microsoft" — doesn't apply to us, because our users are datacenter technicians on company-issued accounts, not Microsoft users. Azure stays a valid choice mainly if our own dev team is already deep in the Microsoft world. A dedicated AWS-vs-Azure pitch deck covers this in full for the decision meeting.

How the move happens: in stages, nothing goes down — foundation, then the app, then the data (the big win), then the AI, then monitoring & hardening. Rough running cost: ~$150–1,200/month depending on size, with the GPU as the swing factor.

Later · governance

Certifications & policies

The certificates and written rules big customers ask for. Mostly process, not code — and correctly begun when a real enterprise deal is on the table. Nothing here is started yet, and that's normal for our stage.

start on demand
The rule to remember: you can only certify a protection you've actually built. Several certificates need the database + backups (next tab) to exist first. Build first, certify second.
○ PRIMARY

ISO 27001 — security certificate

Why The main international proof that our security is real. The headline trust signal for enterprise buyers.
Cost / time A months-long program, roughly $30–100K all-in.
○ PRIMARY

ISO 42001 — responsible-AI certificate

Why A newer standard for governing AI — and a real differentiator, since we're an AI product.
○ CUSTOMER-DRIVEN

SOC 2

Why The report US enterprise buyers ask for first. Weight it higher if we chase the US market.
○

The 8 core policies

Why The written rules (security, access, privacy, incidents, backups…) customers and auditors expect. Policy #5 (secure development) is already largely earned by our audit work; policy #8 (backups) waits for the cloud move.
