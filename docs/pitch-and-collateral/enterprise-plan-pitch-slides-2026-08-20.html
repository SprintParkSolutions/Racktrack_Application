1 · Where we are today

Two very different halves

RackTrack is like a well-built car that hasn't been insured or fitted with alarms yet — the engineering is sound, but the things that let you rely on it every day aren't all in place.

The code — strong
  • Clean, error-free code — both the app and the AI engine held to coding standards.
  • 240 automatic tests, all passing — with coverage now measured.
  • Every screen works on a phone — checked by a robot on all 13 pages.
  • No open security issues — 11 automatic checks run on every change.
  • Nothing secret in the code, and every borrowed library's licence checked.
The setup — demo-stage
  • No backups — one dead hard drive would erase everything, permanently.
  • No alerts — if it breaks at 2am, nobody knows until a tester complains.
  • No company login — so many organisations can't buy it yet.
  • One fragile server — updated by hand, with no test copy and no undo.
  • Untested at scale — nobody knows how many users it holds at once.

2 · The verdict

Good software.
Not yet something a big company can depend on.

What "enterprise level" really means: not prettier code, but whether a large organisation can safely rely on it — is the data backed up, does someone get alerted when it breaks, can a departing employee be locked out. Today RackTrack answers "not yet" — and that's a stage, not a flaw.

are missing

Fix these three, and RackTrack crosses the line from "demo" to "dependable."

1Step oneMove to the cloud

Real infrastructure —
and real backups

Run on AWS or Azure instead of one fragile server. This delivers the single most important fix.

Removes the scariest risk: today, one dead hard drive could erase everything, forever.
A real database — PostgreSQL — saving a scan and its owner as one all-or-nothing action
Automatic nightly backups, stored safely off-site
A tested restore drill — proof we can actually bring the data back
2Step twoOperations + login

Watch it, deploy safely,
let companies log in

The pieces that turn "it works" into "we can run this for real customers."

Now RackTrack is genuinely enterprise-grade — safe, watched, and sellable.
Alerts — an uptime monitor + Sentry crash reports, straight to your phone within a minute
A staging server + one-button deploys with one-command rollback
Company sign-in (SSO) — staff log in through the customer's own system; unblocks corporate sales
3Step threeFinish the audits

Bring in an
outside expert

Now that it's on a live server, we can run the checks that were impossible before.

Why now: a real attack test needs the app running on a real server — which the cloud move gives us.

A penetration test — an outside firm attacks the live app (OWASP method) and writes the report buyers ask for
Sign off the 350-point checklist (OWASP ASVS) and run a live-app scan
A load test, a WCAG accessibility audit, and a published AI-accuracy report

4 · The honest cost

What each
stage really takes

Ballpark figures, not quotes — the exact numbers depend on scale and provider.

Cloud (Steps 1–2) — engineering time + roughly $150–1,200 / month to run, depending on size.
Penetration test (Step 3) — a few thousand dollars, once a year.
Certificates (Step 5) — a larger, one-time investment, only when a real deal calls for it.
